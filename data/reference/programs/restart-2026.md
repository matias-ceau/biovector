## Main ladder — FS / SQ / BP / MP

Fixed-load / rep-state system. Load stays constant; rep-state advances. Third set is always the **+ set**.

| State | Set 1 | Set 2 | Set 3 |
|-------|-------|-------|-------|
| S0 | 3 | 3 | 3+ |
| S1 | 3 | 3 | 4+ |
| S2 | 3 | 4 | 4+ |
| S3 | 4 | 4 | 4+ |
| S4 | 4 | 4 | 5+ |
| S5 | 5 | 5 | 5+ |

**Rep caps:** FS/SQ/BP = 8 · MP = 7

### Advancement

Let *t* = target reps on + set for that state:

- `+ set < t` → repeat state
- `+ set = t or t+1` → advance 1 state
- `+ set ≥ t+2` → advance 2 states
- ugly/rejected set → treat as one bracket lower

### Load increase

At S5, if + set gives **7+ clean** (FS/SQ/BP) or **6+ clean** (MP) → add load, reset to S0.

| Exercise | Jump |
|----------|------|
| FS / BP / MP / PC | +10 kg |
| SQ / DL | +20 kg |

## Deadlift ladder

Shorter ladder. No hero AMRAP deadlifts. **Cap + set at 6.** Max advance = 1 state/session.

| State | Set 1 | Set 2 | Set 3 |
|-------|-------|-------|-------|
| D0 | 3 | 3 | 3+ |
| D1 | 3 | 3 | 4+ |
| D2 | 3 | 4 | 4+ |
| D3 | 4 | 4 | 4+ |
| D4 | 4 | 4 | 5+ |

At D4, if + set = 6 clean → add +20 kg, reset to D0.

---

## Power clean ladder

No + sets. Technical quality is the only advancement criterion.

| State | Scheme |
|-------|--------|
| P0 | 5×1 |
| P1 | 6×1 |
| P2 | 4×2 |
| P3 | 5×2 |
| P4 | 6×2 |

Advance only if every rep is fast, sharp, technically identical.  
At P4, if still crisp → add +10 kg, reset to P0.

## Bench support (B-day)

B-day bench follows A-day bench state. Same load, no + set.

| A-day state | B-day bench |
|-------------|-------------|
| S0–S1 | 3×3 |
| S2–S3 | 3×4 |
| S4–S5 | 3×5 |

During groove rebuild phase: prescribed paused reps (e.g. 5×3 paused).
